# Nightshade 4.0.0 — From your couch. Wake up to a finished image.

The headline release. Run your whole rig from your phone like an ASIAIR — but
with **any** gear, a real autopilot, a built-in planetarium, and a master that's
**finished, diagnosed, and labelled by morning**.

## Highlights

- **Couch-grade remote control.** Drive the entire session from the mobile app:
  one-tap "Tonight", live view, full dashboard. A self-hostable remote-access
  **relay** lets phones connect through a multiplexed tunnel with **no VPN or
  port-forwarding** — the appliance dials out, live view falls back
  WebRTC→WebSocket automatically, and relay connections now persist across
  nights (no re-pairing).
- **An autopilot that thinks.** Adaptive target swapping, horizon and
  meridian-flip gates, multi-night campaigns, and hardened unattended-night
  safety (structural daylight gate, safe-abandon, tracking restore,
  resume-from-checkpoint that actually resumes).
- **Smart Morning Report & finishing.** Wake up to a pristine linear master by
  default, plus an opt-in finishing pipeline — registration, color calibration,
  drizzle, deconvolution — and a layered **Night Doctor** that diagnoses tilt,
  collimation, and marginal-SNR issues with real numbers.
- **Automated mosaics.** Planner → capture → **native WCS stitch** → review UI,
  each panel run under the full autopilot with its own pristine master.
- **Built-in planetarium.** Redesigned dockable UI, a deep-star catalog tier,
  live minor-planet element refresh, and a big first-open performance pass.
- **Built-in multi-star guider, grown up.** Saturation/elongation/edge-star
  rejection, sigma-clipped flux-weighted offsets that shrug off a jumping star,
  and measured Dec-backlash compensation.
- **More gear, less fuss.** Dual-rig synchronized imaging (v1), a calibration
  library manager, device hot-plug recovery, Home Assistant auto-discovery, and
  cloud backup & sync.
- **Cellular push (FCM + APNs).** Push-on-problem alerts when something needs
  you — LAN/Wi-Fi push works out of the box today.
- **Turnkey appliance packaging.** Hardened systemd unit + installer,
  Docker/compose deployment, and a Raspberry Pi (arm64) image builder with a
  first-boot Wi-Fi hotspot.
- **Security & hardening.** CSRF + HttpOnly cookies on the dashboard,
  constant-time token comparison, a CORS allow-list, short-lived WebSocket auth
  tickets, signed LAN-push manifests, and path allow-listing for file browse.

See `CHANGELOG.md` for the complete, itemized list.

> **Android signing note:** this APK is debug-signed for direct sideload
> distribution. It is not a Play Store build; a future production-keystore

## Activating the gated features

Three things live outside the codebase and activate the moment you supply them
(everything else ships and works without them) — see
`docs/4.0-activation-checklist.md`:

1. **iOS release** — the companion app is build-ready but needs a Mac + Apple
   Developer account to sign and submit.
2. **Live cellular push** — server-side FCM/APNs is implemented; it needs your
   Firebase project + APNs key. LAN/Wi-Fi push already works.
3. **On-sky validation** — every finishing algorithm is synthetic- and
   integration-tested; the first clear night is a tuning/validation pass.
